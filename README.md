# 프로젝트 이름 

일정관리챗봇


## 프로젝트 소개

일정관리챗봇은 대화형 인터페이스를 통해 일정을 쉽고 빠르게 관리할 수 있는 웹 애플리케이션입니다.

사용자는 챗봇의 안내에 따라 일정의 제목, 날짜, 시간, 알림 시점을 입력할 수 있으며, 등록한 일정은 달력에서 한눈에 확인할 수 있습니다. 일정 데이터는 로컬 SQLite 데이터베이스에 저장됩니다.

## 만들고 싶은 이유

기존 일정 관리 서비스는 기능이 많아 처음 사용하는 사람이 어렵게 느낄 수 있습니다. 사용자가 복잡한 메뉴를 찾지 않고 챗봇과 대화하듯 일정을 등록하고 관리할 수 있도록 이 프로젝트를 만들었습니다.


## 예상 사용자

- 간단하게 개인 일정을 관리하고 싶은 사용자
- 과제, 시험, 약속 등의 일정을 정리하려는 학생
- 복잡한 캘린더 서비스보다 직관적인 대화형 인터페이스를 선호하는 사용자


## 구현 기능

- [x] 챗봇 안내에 따른 일정 등록
- [x] 단계별 등록과 AI 문장 등록을 선택하는 메뉴
- [x] AI 분석 결과 확인·수정 후 등록 (서버 API 키 설정 필요)
- [x] 일정 제목, 날짜, 시간, 알림 설정
- [x] 등록된 일정 조회 및 상세 정보 확인
- [x] 일정 제목, 날짜, 시간, 알림 수정
- [x] 여러 일정을 선택하여 한 번에 삭제
- [x] 월간 달력과 날짜별 일정 목록 제공
- [x] 오늘의 날짜와 일정 개수 표시

- [x] SQLite 데이터베이스를 이용한 일정 데이터 유지

- [x] 데스크톱과 모바일 화면을 지원하는 반응형 디자인


## 실행 방법

1. [Node.js 24 LTS 이상](https://nodejs.org/)을 설치합니다.

2. Windows에서는 `start-server.cmd`를 더블클릭하거나 프로젝트 폴더에서 다음 명령을 실행합니다.

   ```powershell
   npm.cmd start
   ```

3. 웹 브라우저에서 `http://localhost:3000`을 엽니다.

일정은 처음 실행할 때 생성되는 `data/schedule.db` 파일에 저장됩니다. 기존 브라우저 저장소에 일정이 있으면 데이터베이스가 비어 있는 경우 자동으로 이전됩니다. `index.html` 파일을 직접 열면 데이터베이스 API에 연결할 수 없으므로 반드시 서버를 실행해 접속해야 합니다.


## AI 설정 (선택)

1. [OpenAI API 키](https://platform.openai.com/api-keys)를 준비합니다. 사용 가능한 API 결제·한도가 필요하며 API 사용료가 발생할 수 있습니다.
2. 프로젝트 폴더의 `.env.example`을 복사하고, 복사한 파일의 이름을 `.env`로 바꿉니다. 이미 `.env`가 있으면 덮어쓰지 말고 기존 파일을 사용합니다.
3. `.env`를 열고 `OPENAI_API_KEY=` 뒤에 본인의 API 키를 입력한 다음 저장합니다. `.env.example`의 API 키는 비워 둡니다.

   ```dotenv
   OPENAI_API_KEY=본인의_API_키
   OPENAI_MODEL=gpt-4.1-mini
   ```

4. 실행 중인 서버를 Ctrl+C로 종료한 뒤 `npm.cmd start` 또는 `start-server.cmd`로 다시 실행합니다.
5. 메뉴에서 **AI로 한 번에 등록**을 선택합니다.

`.env.example`은 실제 키 없이 공유하는 설정 예시이고, `.env`는 본인의 실제 키를 보관하는 파일입니다. 서버는 `.env`를 읽습니다.
