# 프로젝트 이름 

일정관리챗봇

## 프로젝트 소개

일정관리챗봇은 대화형 인터페이스를 통해 일정을 쉽고 빠르게 관리할 수 있는 웹 애플리케이션입니다.

사용자는 챗봇의 안내에 따라 일정의 제목, 날짜, 시간, 알림 시점을 입력할 수 있으며, 등록한 일정은 달력에서 한눈에 확인할 수 있습니다. 별도의 서버나 회원가입 없이 브라우저에서 바로 사용할 수 있습니다.

## 만들고 싶은 이유

기존 일정 관리 서비스는 기능이 많아 처음 사용하는 사람이 어렵게 느낄 수 있습니다. 사용자가 복잡한 메뉴를 찾지 않고 챗봇과 대화하듯 일정을 등록하고 관리할 수 있도록 이 프로젝트를 만들었습니다.

## 예상 사용자

- 간단하게 개인 일정을 관리하고 싶은 사용자
- 과제, 시험, 약속 등의 일정을 정리하려는 학생
- 복잡한 캘린더 서비스보다 직관적인 대화형 인터페이스를 선호하는 사용자

## 구현 기능

- [x] 챗봇 안내에 따른 일정 등록
- [x] 일정 제목, 날짜, 시간, 알림 설정
- [x] 등록된 일정 조회 및 상세 정보 확인
- [x] 일정 제목, 날짜, 시간, 알림 수정
- [x] 여러 일정을 선택하여 한 번에 삭제
- [x] 월간 달력과 날짜별 일정 목록 제공
- [x] 오늘의 날짜와 일정 개수 표시
- [x] 브라우저 알림 또는 화면 알림 제공
- [x] 삭제한 일정을 휴지통에 30일간 보관
- [x] 휴지통 일정 복원 및 영구 삭제
- [x] 브라우저 저장소를 이용한 일정 데이터 유지
- [x] 세션 중 챗봇 대화 기록 유지
- [x] 데스크톱과 모바일 화면을 지원하는 반응형 디자인


## 실행 방법

1. 저장소를 복제하거나 ZIP 파일로 내려받습니다.

   ```bash
   git clone <저장소-주소>
   ```

2. 프로젝트 폴더로 이동합니다.

   ```bash
   cd <프로젝트-폴더>
   ```

3. `index.html` 파일을 웹 브라우저에서 엽니다.
